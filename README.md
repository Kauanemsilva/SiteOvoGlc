# Kinetic Blast Lab

Uma experiência web moderna com efeitos visuais impressionantes e animações suaves. Explore a intersecção entre design e tecnologia.

## ✨ Características

- **Elementos 3D Interativos** - Cena Hero 3D imersiva
- **Animações Suaves** - Cursores de penas, explosões de luz e efeitos de partículas
- **Design Moderno** - Construído com Tailwind CSS e componentes responsivos
- **Desempenho Rápido** - Alimentado pelo Vite para carregamentos ultra-rápidos
- **Biblioteca de Componentes** - Componentes UI abrangentes para qualquer projeto

## 🌐 Demo

Visite o site ao vivo: **[https://terraon.vercel.app/](https://terraon.vercel.app/)**

## 🛠️ Stack de Tecnologias

- **Frontend**: React + TypeScript
- **Build**: Vite
- **Styling**: Tailwind CSS
- **Componentes UI**: Shadcn/ui
- **Gerenciador de Pacotes**: Bun
- **Testes**: Vitest
- **Deploy**: Vercel

## 📦 Início Rápido

```bash
# Instalar dependências
bun install

# Executar servidor de desenvolvimento
bun run dev

# Build para produção
bun run build
```
